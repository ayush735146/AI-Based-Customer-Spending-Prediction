# Dataset notes

`mall_customers.csv` is a synthetic learning dataset with 600 rows.

- `CustomerID`: synthetic record ID (excluded from model inputs)
- `Age`: customer age in years
- `Gender`: synthetic categorical descriptor
- `AnnualIncome_k`: annual income proxy in thousands
- `MonthlyVisits`: visits per month
- `AverageBasketValue`: average transaction basket value
- `OnlinePurchaseShare`: estimated share of purchases made online (0–1)
- `LoyaltyYears`: years as a loyalty customer
- `AnnualSpendingCategory`: target class (Low, Medium, High)

No real customer information is included.
